# 俄罗斯做供卵试管的费用总共只要5万吗？

在俄罗斯做供卵试管费用相对还是比较高的，也是不可能只要5万元的。通常来讲，在俄罗斯做一次供卵试管费用需要25万左右，对于供卵试管主要多的是卵子的费用及给供卵者的补偿费用，这部分费用会根据供卵者的年龄、学历、长相、身高等来评估，除此之外还需要试管技术的选择，目前有一二三代试管技术，一二代试管技术的费用相对便宜一点，大概在5万元左右，而三代试管的费用大概是在10万元左右，根据选择的技术不同，费用也会不同。

俄罗斯主要城市的消费水平比较高，其试管婴儿的费用也并不低，尤其是医疗费用，以第三代试管婴儿为例，高达12-15万元/周期，但是俄罗斯助孕补偿费用则相对较低，很多有助孕需求的家庭会选择俄罗斯。下面是关于俄罗斯做供卵试管的费用：

- 1. 前期的检查费用：通常在正式进入试管婴儿周期前都是要求做身体检查的，例如要做AMH、卵泡、性激素六项、精液分析、血型等等，大概需要花费5000元左右，如果这部分在国内做大概2000元左右；
- 2. 卵子的费用及补偿：大概需要花费8-15万不等，会根据供卵者的年龄、学历、身份、身高及长相等进行参考，价格也会有所不同；
- 3. 促排期间的费用：这个期间是需要促排药物治疗的，还需要卵泡监测，大概是需要花费8000元-14000不等；
- 4. 试管技术：根据患者对于试管技术的选择不同，费用也会有所不同，一般做一代二代试管费用差不多就在5万元左右，如果是做三代试管费用基本上就是在10万元人民币左右；
- 5. 其他费用：如机票、签证、吃住行、翻译等，大约是需要5万元人民币，如果是找的跟踪随诊翻译，价格会更高一点。
俄罗斯虽然试管技术还是不错的，但是在供卵试管价格上还是比较贵的，大概需要花费25-30万左右，在前往治疗前一定要提前做好准备，咨询好相关的情况，办理好各种证件。
