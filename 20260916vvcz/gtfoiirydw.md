# 牛！孕妈胎位不正，医生上演“乾坤大挪移”，助力胎宝“华丽转身”

> 更新时间：2026-09-16 (UTC+8)

“非常感谢工人医院产科团队，帮助我宝宝从臀位转成了头位，目前我没有任何不适，宝宝胎心音好，我在等待着自然分娩发动”。

35岁的市民吴女士是二胎孕妈，在孕37周时，胎位一直是臀位，因为一胎是顺产，她强烈希望这次也能顺产。于是她慕名来到柳州市工人医院产科。

在听完吴女士的诉求后，经仔细检查和综合评估，医生发现吴女士B超检查、羊水、胎心监护等各项指标都符合“外倒转”条件，建议可以考虑尝试一下臀位外倒转术。

入院后，吴女士完善了各项辅助检查，由妇产科医师、麻醉医师、B超医师等组成的医疗团队会诊后，制定了严谨的治疗方案，在B超的严密监护下，胡敏副主任及团队为她施行臀位外倒转术，1分钟后，胎宝宝成功转成头位了。

胡敏副主任在徒手“外倒转术”

吴女士在手术室经胎心监护、B超复查及孕妇情况监测，情况良好，无任何不适，转回病房继续监测。

外倒转术究竟是什么？听上去很像武侠小说中的绝世功法，又像是古装剧中的炫酷桥段。

据胡敏副主任介绍：“外倒转术”指的是在妊娠足月，用手法将臀位的胎儿转为头位的技术。孕足月臀位的发生率约3%-4%，臀位自然分娩的胎儿早产、窒息、胎膜早破、脐带脱垂等的发生率较高，因此在我国，臀位是剖宫产的重要指征。而臀位外倒转术，可有效地提高阴道分娩率，降低剖宫产率，在欧美等发达国家已成功开展多年并延续至今。

想要成功实现臀位外倒转术，对医生的经验和技术要求比较高，首先做这类手术需要根据孕妇的意愿进行评估，检查孕周、胎位、胎儿大小、胎盘位置、脐带绕颈、羊水等情况后，才能由具备熟练掌握外倒转术技术的医师进行。术中医生丰富的经验、手法、技术和力量四者缺一不可。

目前，“外倒转术”已经成为柳州市工人医院产科开展的常规技术。
